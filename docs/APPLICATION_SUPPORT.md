# Application support starter reference

Applications is an optional tool under More learning tools. One application and one symptom are shown at a time. The primary Mission, Troubleshoot and My training navigation is preserved.

Initial public context covers CPOF, CPCE, JADOCS, AFATDS/Fires Command Web and Army 365 Teams, email and SharePoint. These are not all laptop installations: CPCE includes hosted services; Army 365 is an enterprise service; the historical JADOCS source specifically describes approved laptops. The dated AFATDS browser example does not establish current deployment requirements.

FSS is pending identification. No expansion, product purpose or configuration is inferred from its acronym.

The bounded selector collects no free text, uploads, credentials or diagnostic logs. Links are static Army informational sources. React renders text without raw HTML. Generic first checks are explicitly editorial hypotheses, with application-owner escalation and a dummy user-task acceptance check. No targeting workflows, installers, commands, operational parameters or interface claims are supplied.

Remaining work: verify public version-specific manuals, authorized deployment prerequisites, current fielding, service ownership and application-expert review. This directory is nonexhaustive. DCGS-A and TAK-family laptop/client distinctions require additional reviewed entries before publication. No production-readiness claim is made.
